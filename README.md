# Vault — คู่มือสั้น

## ไฟล์ในชุดนี้
- `index.html` — ตัวเว็บทั้งหมด (ไม่มี Login ใช้รหัสหลักตัวเดียว)
- `manifest.json`, `sw.js`, `icon*` — ติดตั้งลงหน้าจอหลักมือถือ + ใช้ได้แม้ไม่มีเน็ต
- `supabase-sync.sql` — (ไม่บังคับ) ตารางซิงค์ข้ามเครื่อง
- `VaultCMD/` — `Vault.bat` + `vault.ps1` อ่านไฟล์ `.vault` ที่ export จากเว็บ

## ขึ้นเว็บ (ฟรี)
อัปโหลดไฟล์ในโฟลเดอร์นี้ (ยกเว้น VaultCMD และ .sql) ขึ้น GitHub repo → Settings → Pages → branch main

## เปิดซิงค์ Supabase (ไม่บังคับ)
1. รัน `supabase-sync.sql` ใน SQL Editor
2. ใส่ URL + anon key ที่ ตั้งค่า → ซิงค์คลาวด์ (หรือแก้ค่าบนสุดของ `<script>` ใน index.html ไม่ต้องกรอกใหม่ทุกเครื่อง)

## ย้ายข้อมูลเก่า
หน้าแรก → จากไฟล์ → เลือกไฟล์สำรองของ Vault Ledger เดิม (.json) ใส่รหัสหลักเดิม (ไฟล์แนบ/รูปจะไม่ถูกนำเข้า)

## Vault CMD
ตั้งค่า → ส่งออกไฟล์เข้ารหัส → ได้ `vault-YYYYMMDD.vault` วางข้าง `Vault.bat` แล้วดับเบิลคลิก (ต้องการ Windows 10/11)
เป็นโหมดอ่านอย่างเดียว ไม่ต้องใช้เน็ต


## อัปเดต v2
- ไม่มีระบบซิงค์คลาวด์แล้ว ข้อมูลอยู่ในเบราว์เซอร์ (เข้ารหัส) สำรองด้วยปุ่ม ส่งออกไฟล์เข้ารหัส (.vault)
- รายการชื่อเดียวกันจัดกลุ่มเป็นการ์ดเดียว เช่น Discord (3 บัญชี)
- VaultCMD/Vault.bat: เปิด .vault แบบออฟไลน์ ดูรหัสตามแพลตฟอร์ม และกด i เพื่อบันทึกรูปลง Desktop\VaultImages

## v4
- ซิงค์กลับมาแล้ว (Supabase): รัน supabase-sync.sql ครั้งเดียวต่อฐานข้อมูล แล้วใส่ URL/key ที่หน้าเริ่มใช้งาน
- PIN 4 ตัวขึ้นไป ตัวเลขหรือตัวอักษร
- ตั้งค่า → ย้าย / เปลี่ยนฐานข้อมูล
- ใส่ URL/key ไว้ใน index.html (DEFAULT_SUPABASE_URL/KEY) จะได้ไม่ต้องกรอกบนมือถือ

## v7 (ล่าสุด) — วิธีเข้าใช้งาน
เครื่องแรก: ใส่ Supabase URL + key → ถ้าฐานข้อมูลยังว่าง ระบบให้ตั้ง PIN (ใส่ 2 ครั้ง)
เครื่องอื่น: ใส่ URL + key เดียวกัน → ระบบเจอข้อมูลเดิมเอง → ใส่ PIN เดิมก็เข้าได้เลย
- ฐานข้อมูลเก็บแถวเดียวคงที่ ไม่ผูกกับ PIN: ใส่ PIN ผิด = เข้าไม่ได้ ไม่สร้างข้อมูลใหม่
- ถ้าเช็คฐานข้อมูลไม่ได้ (เน็ตหลุด) ระบบจะไม่ให้สร้างวอลต์ใหม่ทับ
- ปกป้อง URL และ key ให้ดี และส่งออกไฟล์ .vault สำรองไว้เสมอ
