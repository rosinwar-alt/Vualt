# Vault — คู่มือสั้น

## ไฟล์ในชุดนี้
- `index.html` — ตัวเว็บทั้งหมด (ไม่มี Login ใช้ PIN ตัวเดียว)
- `manifest.json`, `sw.js`, `icon*` — ติดตั้งลงหน้าจอหลักมือถือ + เปิดได้แม้ไม่มีเน็ต
- `supabase-sync.sql` — ตารางซิงค์ข้ามเครื่อง (รันครั้งเดียวต่อฐานข้อมูล)
- `VaultCMD/` — `Vault.bat` + `vault.ps1` อ่านไฟล์ `.vault` แบบออฟไลน์

## ขึ้นเว็บ (ฟรี)
อัปโหลดไฟล์ในโฟลเดอร์นี้ (ยกเว้น VaultCMD และ .sql) ขึ้น GitHub repo → Settings → Pages → branch main

## เข้าใช้งานครั้งแรก
1. ใส่ Supabase URL + key (หรือกด "ข้าม" ใช้ในเครื่องก่อน)
2. ฐานข้อมูลว่าง → ตั้ง PIN (พิมพ์ 2 ครั้ง) · มีข้อมูลเดิมอยู่แล้ว → ใส่ PIN เดิมเข้าได้เลย
3. ใส่ PIN ผิด = เข้าไม่ได้ ไม่สร้างข้อมูลใหม่ (ฐานข้อมูลมีแถวเดียวคงที่)

## v8 — ประเภทและหมวดหมู่
กด ＋ แล้วเลือกก่อนว่าจะเพิ่มอะไร:
- **รหัสผ่าน & ข้อมูลลับ**: บัญชีเว็บ/แอป · เกม · อีเมล · ธนาคาร&เงิน · บัตรเครดิต/เดบิต · Wi-Fi · คีย์&โค้ด · โน้ตลับ
- **รูป & เอกสาร**: รูปภาพ (สลิป/QR/ภาพหน้าจอ) · เอกสารสำคัญ (บัตรประชาชน/พาสปอร์ต/ใบขับขี่) — เลือกรูปหรือถ่ายรูปได้ ขยายดูเต็มจอ ดาวน์โหลดได้
- **ประเภท** = ชนิดของรายการ (กำหนดช่องกรอกและไอคอน) · **หมวดหมู่** = โฟลเดอร์ที่คุณตั้งเอง (งาน, ครอบครัว ฯลฯ) จัดการได้ที่ ตั้งค่า → จัดการหมวดหมู่
- เลือกไอคอน (อีโมจิ) ให้แต่ละรายการได้ · มีชื่อบริการแนะนำกว่า 100 รายการตามประเภท
- ลบแล้วกด "เลิกทำ" ได้ · ปุ่มทำสำเนา (เหมาะกับหลายบัญชีของบริการเดียวกัน)
- ข้อมูลในเครื่องเก็บด้วย IndexedDB (รูปเยอะได้) · ซิงค์ทั้งก้อนผ่าน Supabase จึงไม่ควรเก็บรูปเกินหลายสิบ MB
- เปลี่ยน PIN: ซิงค์ให้ตรงกันก่อน แล้วเขียนทับด้วย PIN ใหม่ เครื่องอื่นใส่ PIN ใหม่ตอนเปิดครั้งหน้าก็ดึงข้อมูลให้เอง

## ข้อควรระวัง
- ใครมี URL + key ของ Supabase จะดึง/ลบแถวที่เข้ารหัสไว้ได้ (ถอดรหัสไม่ได้ถ้าไม่มี PIN) — เก็บไว้ดีๆ และส่งออกไฟล์ `.vault` สำรองเป็นระยะ
- ยังไม่รองรับไฟล์เพลง/วิดีโอ (mp3/mp4)
